# Landing-page coastline

Source: [Natural Earth 1:50m land](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_land.geojson).

License: [Public domain](https://www.naturalearthdata.com/about/terms-of-use/).

Downloaded 2026-10-16. Parsed snapshot SHA-256: 688964a4dde767bb8e8cc5c7e155947bb3f4bc7676917b42b716e280142885ed.

The Borneo land polygon was selected by containment of 114°E, 1°N and projected to a 600 × 480 illustration using Mercator coordinates, a 107–120.5°E / 5°S–8°N frame, uniform scale and padding. Original coastline vertices were retained, rounded to two SVG pixels. This is a presentational coastline, not approved district geometry, an access boundary or a risk layer. The landing-page markers are synthetic demonstration UI and are labelled accordingly. No NASA observations are bundled.
